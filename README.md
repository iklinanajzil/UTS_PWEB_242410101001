Deskripsi Project
StockTrack adalah aplikasi manajemen investasi yang mengusung tema Green Finance. Aplikasi ini dibuat menggunakan Laravel 13 murni dengan arsitektur MVC untuk mensimulasikan alur login pengguna hingga pengelolaan aset portofolio secara dinamis.
